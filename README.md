# DialogFix

Selects the first input field when opening a dialog.

## Links

- Modrinth: https://modrinth.com/mod/dialogfix
- Dev builds: https://build.florianreuth.de/job/DialogFix

## Use in Gradle

If you want to depend on DialogFix in your own project, use the Maven repository here:

https://maven.florianreuth.de/#/releases/de/florianreuth/dialogfix

The repository page includes the latest coordinates and setup instructions.
